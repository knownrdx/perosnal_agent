How this works

Runs entirely without the LLM (deterministic), so a slow or down LLM provider never stops it. There is one dedicated chat thread for this - open it below, drop your number files in it, then type start (or done). Files sent in any other thread are left alone, so there is never any doubt about where a file goes. The agent decides each file's tag on its own from the filename when it can, and only asks when it genuinely has nothing to go on. Type stop any time to pause the periodic checks.
