Add a ChatGPT-style Chat panel to the web dashboard

Every other panel is a control surface - tasks, jobs, contacts - but there
was no way to just talk to the agent from the browser the way Telegram
already lets you. Fixed.

Backend: two new endpoints reusing the existing brain

POST /api/chat and GET /api/chat/history both call the exact same
app.agent.conversation.handle_message()/recent_messages() that Telegram's
"just talk to me" flow already uses, against the owner's chat_id
(settings.owner_chat_id). No new conversation engine, no new memory store -
a message sent from the web dashboard and one sent from Telegram are one
continuous conversation either surface can see, same task-creation routing,
same self-learning, same follow-up detection.

Frontend: a real chat UI, not a form

New "Chat" panel (now the default landing panel) - message bubbles,
right-aligned for the owner, left for the agent, auto-scrolling, a
"Thinking..." indicator while waiting, Enter to send / Shift+Enter for a
newline, an auto-growing textarea. History loads once per session on first
visit to the panel. Every request goes through the same credentials-include
+ 401-redirects-to-login fetch wrapper the rest of the dashboard already
uses - no separate auth path to get wrong.

561 tests (3 new, covering send+history round-trip, auth-required, and
cookie-only access), full suite green.
