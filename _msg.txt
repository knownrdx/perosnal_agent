Runs that end on their own: re-add limits, time limits, auto-delete

A started country ran until the owner remembered to stop it, and every
interval/restock value had to be one of the fixed button choices.

Finish conditions, per country
  max_refills stops after N re-adds; run_minutes stops N minutes after the
  run started. 0 means no limit, so the previous behaviour is the default.
  Both are checked BEFORE a re-add rather than after - "run it twice" has to
  mean twice, not three times.

  Refill counts and start times are tracked per country and persisted, so a
  restart does not reset a half-finished run. One country reaching its limit
  retires only that country; siblings keep going.

delete_when_done
  When a run ends, optionally clear that country's numbers off the target
  bot with /frcd. Opt-in: the deletion is irreversible on the bot's side, so
  a run merely ending must never trigger it by default.

  Two failure modes are handled rather than silently ignored: with no uid
  configured the command would go out as a literal "/frcd Bangladesh {uid}",
  which the bot accepts and does nothing with - that now reports the missing
  uid instead of sending junk. And if the delete fails for any reason the
  run still ends, so a failed cleanup cannot leave a country cycling
  forever.

  Finishing is reported as its own "Task shesh" notification, separate from
  the stock-empty alert, so a completed run never reads as a failure.

Custom values everywhere
  The button lists (5/10/15/30/60 min, 0/100/200/500/1000/5000 left) are
  shortcuts, not the range. Each keyboard gained a custom option that asks
  for a value and reads the owner's next message, so 7 minutes or 1500 left
  are reachable from Telegram. A rejected value keeps the question open
  rather than dropping it, since the owner clearly meant to answer it.

  Also added a restock-point picker (global and per country) - previously
  the threshold could only be set from the web form, so from Telegram a
  country could only ever refill at zero.

New preset "One-shot burst": refills at 200 left, stops after 5 re-adds,
then clears the country. Per-country settings, the schedule table and both
UIs carry the new fields.

717 passing, smoke 10/10.
