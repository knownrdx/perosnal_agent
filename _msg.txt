File uploads now show up as a permanent chat message

An upload only ever wrote to invisible session context
(pending_upload) - the file itself never appeared in the actual chat
history, so reloading the Chat panel (or scrolling Telegram) made it look
like nothing had been uploaded at all, even though it was attached and
working underneath.

Fix: both upload paths (app/api.py's POST /api/chat/upload and
app/telegram/bot.py's F.document handler) now also write a normal "user"
message ("Uploaded: <name>") into the conversation, on the chat's current
thread, right alongside setting pending_upload. It is a real, permanently
stored chat turn - it survives a page reload and shows up in
GET /api/chat/history exactly like any other message, from either surface.

565 tests (1 updated to assert the upload appears in history), all green.
